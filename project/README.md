# project/

The workspace. Each command writes its output here, so a project's thinking
lives beside its code rather than in a chat log.

  brief/          the incoming brief, and `/discover` research
  design-system/  `/tokenize` output
  screens/        `/design-screen` output
  reviews/        `/slop-check`, `/ux-audit` and accessibility passes
  handoff/        `/handoff` output
  STATE.md        working memory for this project, written as you go

Nothing here is created for you. The folders appear when a command first needs
them, and `STATE.md` is worth starting by hand on day one.
